# Day 01: Network Devices & Architecture

### 📌 Overview
Understanding fundamental hardware components in a computer network, their roles in the OSI/TCP-IP stack, and how frames vs. packets are handled.

---

### 🧠 Core Concepts

- **Host (End Device):** Any network node that requests or delivers services and holds an IP address (PCs, Servers, Printers).
- **Hub (Layer 1):** Legacy multi-port repeater. Operates in a single collision domain; broadcasts all incoming electrical signals to every port.
- **Switch (Layer 2):** Intelligent device maintaining a MAC address table. Forwards frames directly to the intended destination port within a Local Area Network (LAN).
- **Router (Layer 3):** Connects different IP networks/subnets. Routes packets based on IP routing tables and acts as the Default Gateway for local hosts.
- **Firewall:** Monitors and filters incoming/outgoing network traffic based on configured security rules.
